# SQL — Часть 2: Сортировка и ограничение результатов

## 1. ORDER BY — сортировка результатов

### Синтаксис:
```sql
SELECT столбцы
FROM таблица
ORDER BY столбец [ASC/DESC];
```

- **ASC** (Ascending) — по возрастанию (используется по умолчанию, можно не писать)
- **DESC** (Descending) — по убыванию

### Пример: отсортировать пользователей по возрасту (от младшего к старшему)
```sql
SELECT * FROM users
ORDER BY age ASC;
```

**Результат:**
| id | name | age |
|----|------|-----|
| 3 | Пётр | 17 |
| 1 | Иван | 25 |
| 2 | Мария | 30 |
| 4 | Анна | 45 |

### Пример: от старшего к младшему
```sql
SELECT * FROM users
ORDER BY age DESC;
```

---

## 2. LIMIT — ограничение количества результатов

### Синтаксис:
```sql
SELECT столбцы
FROM таблица
LIMIT число;
```

### Пример: показать только первых 2 пользователей
```sql
SELECT * FROM users
LIMIT 2;
```

**Результат:** только Иван и Мария (первые 2 строки таблицы)

### Частое комбо — LIMIT + ORDER BY (очень полезно на практике!)

**Найти самого молодого пользователя:**
```sql
SELECT * FROM users
ORDER BY age ASC
LIMIT 1;
```

**Результат:** только Пётр (17 лет)

💡 **Практическое применение для QA:** Такой запрос часто нужен, чтобы быстро найти "последнюю запись в логах" или "самый последний созданный заказ" — сортируем по дате DESC + LIMIT 1.
