## Что такое SQL вообще?

**SQL (Structured Query Language)** — язык для общения с базами данных. Представь базу данных как **набор таблиц** (похоже на Excel-файлы), а SQL — это способ **задавать вопросы** этим таблицам.

## Представим таблицу для примеров

Допустим, у нас есть таблица `users` (пользователи):

| id | name | email | age | city |
|----|------|-------|-----|------|
| 1 | Иван | ivan@mail.com | 25 | Москва |
| 2 | Мария | maria@mail.com | 30 | Томск |
| 3 | Пётр | petr@mail.com | 17 | Москва |
| 4 | Анна | anna@mail.com | 45 | Казань |

---

## 1. SELECT + FROM — "Что показать" и "Откуда"

### Базовый синтаксис:
```sql
SELECT столбцы
FROM таблица;
```

### Пример: показать всех пользователей, все столбцы
```sql
SELECT * FROM users;
```
💡 Звёздочка `*` означает "все столбцы"

**Результат:** покажет всю таблицу целиком (все 4 строки, все 5 столбцов)

### Пример: показать только конкретные столбцы
```sql
SELECT name, email FROM users;
```

**Результат:**
| name | email |
|------|-------|
| Иван | ivan@mail.com |
| Мария | maria@mail.com |
| Пётр | petr@mail.com |
| Анна | anna@mail.com |

---

## 2. WHERE — "При каком условии"

Это как **фильтр** — показывает только те строки, которые соответствуют условию.

### Синтаксис:
```sql
SELECT столбцы
FROM таблица
WHERE условие;
```

### Пример: найти пользователя из Москвы
```sql
SELECT * FROM users WHERE city = 'Москва';
```

**Результат:**
| id | name | email | age | city |
|----|------|-------|-----|------|
| 1 | Иван | ivan@mail.com | 25 | Москва |
| 3 | Пётр | petr@mail.com | 17 | Москва |

### Операторы сравнения в WHERE:

| Оператор | Значение | Пример |
|----------|----------|--------|
| `=` | равно | `WHERE age = 25` |
| `!=` или `<>` | не равно | `WHERE city != 'Москва'` |
| `>` | больше | `WHERE age > 18` |
| `<` | меньше | `WHERE age < 18` |
| `>=` | больше или равно | `WHERE age >= 18` |
| `<=` | меньше или равно | `WHERE age <= 18` |

### Комбинирование условий: AND / OR

```sql
-- Пользователи из Москвы старше 18 лет
SELECT * FROM users 
WHERE city = 'Москва' AND age >= 18;
```

**Результат:** только Иван (25 лет, Москва) — Пётр не подходит, ему 17

```sql
-- Пользователи из Москвы ИЛИ из Казани
SELECT * FROM users 
WHERE city = 'Москва' OR city = 'Казань';
```

**Результат:** Иван, Пётр, Анна

## 🔑 Важное для QA! Оператор LIKE (поиск по шаблону)

Часто нужно искать не точное совпадение, а **часть строки**:

```sql
-- Найти всех пользователей, чей email содержит "mail.com"
SELECT * FROM users WHERE email LIKE '%mail.com%';
```

**Символ `%`** означает "любые символы до/после". Это очень полезно для тестировщика — например, найти все записи, где в логах есть слово "error".
