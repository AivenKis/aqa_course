### Часть 1: Теория

Перед тем как ты начнёшь писать код, я дам тебе **чёткую и структурированную теорию** по всем инструментам, которые понадобятся в задаче «Анализатор имени».

### 1. `input(prompt)`

- **Что делает**: Выводит подсказку пользователю и возвращает введённые данные в виде **строки** (`str`).
- **Важно**: Всегда возвращает `str`, даже если пользователь ввёл число.
- **Хорошая практика**: Почти всегда использовать `.strip()` после `input()`.

Пример:
```python
name = input("Введите имя: ")        # возвращает строку
name = input("Введите имя: ").strip()  # убирает лишние пробелы
```

---

### 2. `.strip()`

- **Что делает**: Удаляет все пробельные символы **в начале и конце** строки.
- **Зачем нужен**: Чтобы пользователь не мог ввести только пробелы (`"   "`), и программа их приняла как валидные данные.
- **Пример**:
```python
print("  hello world  ".strip())   # → "hello world"
print("   ".strip())               # → "" (пустая строка)
```

---

### 3. `.split()`

- **Что делает**: Разбивает строку на **список** слов.
- По умолчанию разбивает по пробелам.
- **Когда использовать**: Когда нужно разделить "Имя Фамилию" на две части.

Пример:
```python
full = "Ivan Petrov Sidorov"
print(full.split())        # → ['Ivan', 'Petrov', 'Sidorov']
print(full.split()[0])     # → Ivan
```

---

### 4. `.upper()`

- **Что делает**: Преобразует **все** буквы строки в верхний регистр.
- **Важно**: Работает только с буквами, цифры и символы не меняет.

Пример:
```python
print("ivan petrov".upper())          # → "IVAN PETROV"
print("Мария-Лонгория".upper())      # → "МАРИЯ-ЛОНГОРИЯ"
```

---

### 5. f-строки (f"...")

- **Что делает**: Позволяет вставлять переменные и выражения внутрь строки с помощью `{}`.
- Самый удобный и современный способ форматирования строк в Python.

Пример:
```python
name = "Алексей"
print(f"Привет, {name}!")                    # → Привет, Алексей!
print(f"Длина: {len(name)} символов")       # → Длина: 6 символов
```
