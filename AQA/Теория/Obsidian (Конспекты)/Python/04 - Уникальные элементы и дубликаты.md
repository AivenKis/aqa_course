# Тема: Уникальные элементы и дубликаты

## Объясняю просто:

Представь **коробку с карточками**, где некоторые карточки повторяются. Тебе нужно сделать **две новые коробки**:

1. Одну — где каждая карточка встречается **только один раз** (без повторов)
2. Другую — куда положить только те карточки, которые **повторялись** (были дубликатами)

---

### 🔑 7 ключевых пунктов:

**1. Что такое дубликат?** Дубликат — это элемент, который встречается в списке **больше одного раза**.

**2. Способ 1: Использовать `set()` для удаления дубликатов** `set` (множество) — это структура данных, которая **автоматически** не хранит повторяющиеся значения:

`numbers = [1, 2, 2, 3, 4, 4, 4, 5] unique = list(set(numbers))`

⚠️ Минус: `set` **не сохраняет порядок** элементов!

**3. Способ 2: Вручную через цикл (сохраняет порядок)**

`unique = [] for num in numbers: if num not in unique: unique.append(num)`

**4. Оператор `in` — проверка "есть ли элемент в списке"**

`5 in [1, 2, 3] # → False 2 in [1, 2, 3] # → True`

**5. Оператор `not in` — противоположность**

`5 not in [1, 2, 3] # → True (действительно нет в списке)`

**6. Как найти именно дубликаты (второй список)** Логика: если элемент **уже есть** в списке уникальных — значит, это повтор, и его нужно положить в список дубликатов.

**7. Разница между "список уникальных" и "список дубликатов"**

- **Уникальные** — каждое значение по одному разу (даже если повторялось 100 раз в оригинале)
- **Дубликаты** — только те значения, которые повторялись (иногда там могут быть повторы самих повторов — зависит от логики)

---

### 💡 3 простых примера:

**Пример 1: Проверка `in`**

`fruits = ["яблоко", "банан"] print("яблоко" in fruits) # → True print("груша" in fruits) # → False`

**Пример 2: Удаление дубликатов вручную**

`data = [1, 1, 2, 3, 3, 3] unique = [] for item in data: if item not in unique: unique.append(item) print(unique) # → [1, 2, 3]`

**Пример 3: Поиск дубликатов**

`data = [1, 1, 2, 3, 3, 3] seen = [] duplicates = [] for item in data: if item in seen: duplicates.append(item) else: seen.append(item) print(duplicates) # → [1, 3, 3] (каждое повторное появление фиксируется)`
